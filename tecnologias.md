# 🚀 Tecnologías para nuestra App Web

## 🎨 Frontend (Diseño y cliente)
Usaremos React.js porque permite crear interfaces de usuario interactivas y reutilizables mediante componentes.
## ⚙️ Backend (Servidor y Base de Datos)
Elegimos Node.js con Express por su alto rendimiento, arquitectura orientada a eventos y uso de JavaScript en todo el stack.
